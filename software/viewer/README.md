# viewer — KOGUMA MK4 ビューア(ログを見る・コマンドを送る・書き込む)

`viewer.html` 1 つだけで動きます(2026-11-28)。KOGUMA(`KOGUMA.MkIIl` の `tools/viewer.html`)のビューアに、MK4 のログと無線・書き込みを足しました。
ログの決まりは [../../docs/log.md](../../docs/log.md)、無線と書き込みの決まりは [../../docs/ble.md](../../docs/ble.md) の 3〜6 章。

## 開き方

1. `viewer.html` を **Chrome か Edge** で開く(ファイルをブラウザにドラッグする。Firefox・Safari は有線も無線も使えない)
2. 上の「有線で接続」(STLINK の仮想 COM ポートを選ぶ)か「無線で接続」(`KOGUMA-MK4` を選ぶ)を押す
3. 右上に「接続中 …」と出れば成功

## できること

| 場所 | すること |
|---|---|
| 左の一覧 | 機体から届いたログ(`#BEGIN LOG …` 〜 `#END LOG`)が 1 つずつ並ぶ。押すとグラフが出る |
| 「ファイルを開く」 | 前に保存したログ(`.txt`)を読む |
| 「保存先フォルダ」 | 選ぶと、届いたログを 1 つずつファイルにして自動で保存する(`software/main-controller/logs/` を選ぶ) |
| 下のコマンドの欄 | 1 行打って Enter で機体に送る(`get log`、`log current` など。`docs/log.md` の 6 章) |
| 「書き込み」 | `.bin`(`build/Release/KOGUMA-Mk4.bin`)を選んで「書き込む」。ブートローダに入れて、4KB ずつ送り、CRC を確かめる(`tools/fw.py` と同じ手順) |

ログの種類ごとのグラフ:
- `run`・`tune`(走行ログ): 速度・加速度・角速度・角度・電流・duty・電池・壁センサ・壁の距離・壁の制御・動作 など
- `current`(電流のログ 20kHz): 電流の目標と測った値・duty・電池・車輪の速度
- `sensor`(壁センサの生の値): 消灯・点灯・順番 3 の値と、点灯 − 消灯
- `explore`(探索の判断): 区画ごとの壁・選んだ動き・計算の時間の表とグラフ

## 書き込みがうまくいかないとき

- 有線で「返事がない」: 走るプログラムが壊れているか止まっている。機体の電源を入れ直して、10 秒の間にもう一度「書き込む」(ブートローダが待っている)
- 無線では、返事がなければ自動で `@flash` を送り、HY0020 がブートローダに入れる
- 途中で切れても、もう一度「書き込む」を押せば書き直せる(先頭の 1KB は最後に書くので、壊れたプログラムには飛ばない)
