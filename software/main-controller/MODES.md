# 操作とモード

KOGUMA MK4 の機体の操作、LED・ブザーの表し方、モードの割り当てです。**ToraNeko.Mk3 の `MODES.md`(`Tokoro0917/toraneko.mk3` の `software/main-controller/MODES.md`)と同じ**にします(2026-11-23 決定)。ステップ9 で `sys/mode.c`・`sys/ui.c` を作るときに、ToraNeko の `MODES.md` をここに写して、下の違いを入れます。

## ToraNeko と同じもの

- 操作の流れ: 左タイヤでモード(0〜7)、右タイヤで No.(0〜15)を選ぶ → スイッチ(MK4 は **SW2**)で決定 → 前センサに手をかざして離す → 1 秒後に走り出す → 走り終わったら同じモード・No. に戻る
- LED の表し方: 真ん中の 3 個がモード(4・2・1)、外側の 4 個が No.(8・4・2・1)。合図(ロード中・決定・スタート待ち・うまくいった・できなかった・保存中・電池が少ない・フェイルセーフ・走っている間の壁)も同じ
- モードの割り当て: 0 探索、1 最短走行、2 探索のターン調整、3 最短走行のターン調整、4 実験用、5 センサ、6 基本調整、7 出力と設定。どのモードも No.0 は何もしない
- 迷路の保存と呼び出し(モード7 No.15)

## MK4 で違うもの

| もの | MK4 | ToraNeko |
|---|---|---|
| LED の並び | t24 の基板: 左の角 2 個(No. の 8・4 = D96・D95)、V 字の先 3 個(モードの 4・2・1 = D92・D91・D90)、右の角 2 個(No. の 2・1 = D94・D93) | LED1・2、LED3〜5、LED6・7 |
| ブザー | **あり**。LED の合図と一緒に短い音(決定・スタート・うまくいった・できなかった・フェイルセーフ)。音を消す設定も持つ。音の割り当ては作るときに決める | なし |
| 前の LED(D98) | BLE がつながっている間は点ける(案) | なし |
| スイッチ | SW2(SW1 は電源) | SW1 |
| モード0 探索 | 吸引ありの探索も足す(KOGUMA の吸引探索を確かめてから) | 吸引なしだけ |
| モード3 | `turn_test`(PC から値を送って走り、ログを返す) | ターンを 1 つずつ |
| モード4 実験用 | 電流の制御の確かめ、モーターの同定(巻線抵抗・インダクタンス・Kt)、電流のステップ応答 | モーターの速さ・定数、吸引の力、加速度の限界 |
| モード6 基本調整 | エンコーダの校正(MT6835 の CAL_EN) | エンコーダの歪みを測る |
| モード7 出力 | BLE がつながっていれば、走り終わりに自動でも送る | ケーブルで出すだけ |
| コマンド | BLE・UART の `run` でも同じ流れ(手をかざして離す)で走る | なし |
| 保存の場所 | Flash のセクタ 4・5(パラメータ・迷路・ゴール) | セクタ 6・7 |
