# タイヤ24mm の機体の注文する部品(Fusion で確かめる用、2026-11-23)

ブランチ `claude/trusting-dirac-1tdt54`。`../vehicle/export_t24_parts.py` が機体のモデル `../vehicle/mk4_vehicle_t24.step`(60.66g、ぶつかりなし。2026-11-24 にホイールを窓なし・円板 1.2mm(t24v3)にした。2026-11-24 に平行ピンを 3×8 にした。2026-11-23 にフレームを 0.8mm・吸引する面を埋めた形 t24v10 にして作り直した)から1つずつ書き出す。

STEP の丸い所(穴・窓の角・外形の丸み)は本当の円弧で書いてある(2026-11-24 から。`../cq_arcs.py`。それまでは細かい折れ線でギザギザだった)。

**座標は機体と同じ**(原点は車軸の真ん中、+x が前、+y が左、z は床から上、単位 mm)。Fusion で全部を原点に挿入すると、組み上がった位置に並ぶ。印刷する部品は STL も(JLC3DP に出す用。向きは JLC3DP の画面で決める)。
