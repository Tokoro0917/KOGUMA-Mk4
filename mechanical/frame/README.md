# フレームの製作用ファイル(frame v6)

今の形の DXF・型紙・3D。形の計算と経緯は`docs/frame.md`、作り直しは`docs/calc/frame/`のスクリプト(`docs/frame.md`の「計算をやり直すには」)。

| ファイル | 中身 | 使い方 |
|---|---|---|
| `MK4FRAME60_T1.dxf` | カーボン板 1mm の外形・窓・タイヤの穴と M2 の穴 φ2.3 × 7。実線だけ、1:1、単位 mm | **カーボンラボ.jp に出すのはこれ**。厚さ1mm・綾織・クロス・マット。備考に「繊維の向きは図の X 方向(前後)を 0°に」 |
| `MK4PC60_T02.dxf` | ポリカーボネート 0.2mm の外形(2枚) | レーザー加工に出すとき |
| `MK4PC60_template_A4_1to1.pdf` | ポリカーボネートの型紙 | 「実際のサイズ」で印刷し、カッターで切る。フレームの上面に貼る |
| `frame_v6.dxf` | カーボン・穴・ポリカーボネート・文字をレイヤーで分けたもの | Fusion 360 で読み込んで確かめる・直す |
| `frame_v6_3d.step` | カーボン板とポリカーボネートの3D | Fusion 360 で機体に組む |

座標は、原点が車軸の中心、+x が前、+y が左。大きさは 101.0 × 70.6mm、カーボン約 4.69g。

前の版の DXF は`docs/calc/frame/frame_v4.dxf`〜`frame_v5.dxf`(レイヤー別)にある。
