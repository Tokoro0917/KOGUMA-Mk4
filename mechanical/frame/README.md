# フレームの製作用ファイル(frame v6.7)

今の形の DXF・型紙・3D。形の計算と経緯は`docs/frame.md`、作り直しは`docs/calc/frame/`のスクリプト(`docs/frame.md`の「計算をやり直すには」)。

| ファイル | 中身 | 使い方 |
|---|---|---|
| `MK4FRAME67_T1.dxf` | カーボン板 1mm の外形・窓・タイヤの穴と M2 の通し穴 φ2.2 × 4。実線だけ、1:1、単位 mm | **カーボンラボ.jp に出すのはこれ**。厚さ1mm・綾織・クロス・マット。備考に「繊維の向きは図の X 方向(前後)を 0°に」 |
| `MK4PC67_T02.dxf` | 硬質塩ビ 0.2mm の外形(2枚) | レーザー加工に出すとき |
| `MK4PC67_template_A4_1to1.pdf` | 塩ビの型紙 | 「実際のサイズ」で印刷し、カッターで切る。フレームの上面に貼る |
| `frame_v6_7.dxf` | カーボン・穴・塩ビのシート・文字をレイヤーで分けたもの | Fusion 360 で読み込んで確かめる・直す |
| `frame_v6_7_3d.step` | カーボン板と塩ビのシートの3D | Fusion 360 で機体に組む |

DXF の線は、直線と本当の円弧(LWPOLYLINE の bulge)、丸い穴は CIRCLE で書いてある(折れ線ではない。`docs/calc/frame/dxf_arcs.py`)。

座標は、原点が車軸の中心、+x が前、+y が左。大きさは **100 × 70mm**(x −50〜50、y −35〜35)、カーボン約 5.5g(吸引ファンの真下 φ35 はカーボンで埋めてある。穴は真ん中の φ15 だけ)。吸引する面(塩ビ 0.2mm を貼る所)は **60 × 30mm**(x −30〜30、y −15〜15)。

## 壁センサのホルダを当てる所(frame v6.7、2026-10-31)

壁センサのホルダ(v3、`mechanical/sensor_holder/`)の下の端を、両面テープでフレームに貼る。ホルダ(後ろの足を含む)の真下と、そのまわり 1mm には窓を開けない(`docs/calc/frame/design.py` の `SENSOR_PAD_M`、位置は `mechanical/vehicle/pcb_shape.py` の `SENS`)。4つとも、ホルダの下(45mm²)がすべてカーボン。

## ねじの穴(M2、通し穴 φ2.2。2026-10-20 に 2.3 から)

中心はどれも 1mm 単位。穴の間の距離(x・y 方向)も、外形の角からの距離も整数の mm。

| 穴 | 車軸から (x, y) | 外形の左下の角 (−50, −35) から |
|---|---|---|
| モーターマウント 後ろ | (−17, ±22) | (33, 13)、(33, 57) |
| モーターマウント 前 | (8, ±22) | (58, 13)、(58, 57) |

穴の間: マウントの前後 25、左右 44。(2026-10-20 にファンの台の左右の柱 (22, ±18) の穴、続けて前の耳 (33, 0) の穴もなくした。ファンの台はモーターマウントの腕 (14, ±22) だけで持つ)

前の版の DXF は`docs/calc/frame/frame_v4.dxf`〜`frame_v6_6.dxf`(レイヤー別)にある。
