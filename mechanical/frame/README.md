# フレームの製作用ファイル(frame v6.1)

今の形の DXF・型紙・3D。形の計算と経緯は`docs/frame.md`、作り直しは`docs/calc/frame/`のスクリプト(`docs/frame.md`の「計算をやり直すには」)。

| ファイル | 中身 | 使い方 |
|---|---|---|
| `MK4FRAME61_T1.dxf` | カーボン板 1mm の外形・窓・タイヤの穴と M2 の穴 φ2.3 × 7。実線だけ、1:1、単位 mm | **カーボンラボ.jp に出すのはこれ**。厚さ1mm・綾織・クロス・マット。備考に「繊維の向きは図の X 方向(前後)を 0°に」 |
| `MK4PC61_T02.dxf` | ポリカーボネート 0.2mm の外形(2枚) | レーザー加工に出すとき |
| `MK4PC61_template_A4_1to1.pdf` | ポリカーボネートの型紙 | 「実際のサイズ」で印刷し、カッターで切る。フレームの上面に貼る |
| `frame_v6_1.dxf` | カーボン・穴・ポリカーボネート・文字をレイヤーで分けたもの | Fusion 360 で読み込んで確かめる・直す |
| `frame_v6_1_3d.step` | カーボン板とポリカーボネートの3D | Fusion 360 で機体に組む |

座標は、原点が車軸の中心、+x が前、+y が左。大きさは **100 × 70mm**(x −50〜50、y −35〜35)、カーボン約 4.66g。

## ねじの穴(M2、φ2.3)

中心はどれも 1mm 単位。穴の間の距離(x・y 方向)も、外形の角からの距離も整数の mm。

| 穴 | 車軸から (x, y) | 外形の左下の角 (−50, −35) から |
|---|---|---|
| モーターマウント 後ろ | (−17, ±22) | (33, 13)、(33, 57) |
| モーターマウント 前 | (8, ±22) | (58, 13)、(58, 57) |
| ファンの台 左右の柱 | (22, ±18) | (72, 17)、(72, 53) |
| ファンの台 前の耳 | (33, 0) | (83, 35) |

穴の間: マウントの前後 25、左右 44。ファンの柱の左右 36。マウントの前 → ファンの柱 x 14・y 4。ファンの柱 → 前の耳 x 11・y 18。マウントの後ろ → 前の耳 x 50。

前の版の DXF は`docs/calc/frame/frame_v4.dxf`〜`frame_v6.dxf`(レイヤー別)にある。
