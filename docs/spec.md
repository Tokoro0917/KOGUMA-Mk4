# KOGUMA MK4 設計仕様

KOGUMA MkIIl(MK3、[tokoro0917/koguma.mkiil](https://github.com/tokoro0917/koguma.mkiil))の後継機。2026-10-09時点。まずハードを決める。

## 目標

- クラス: **クラシック(16×16)**
- 重点: 走行速度・加速 / メモリ・計算能力 / 調整・運用のしやすさ

## 決まったこと

| 項目 | 決定 | 理由 |
|---|---|---|
| クラス | クラシック16×16 | |
| 駆動方式 | 2輪(MK3と同じ) | |
| モーター | **NFP-D8620-3665-3-7.4**(8.6×20mm コアレス、7.4V版)を**片側1個** | 下記「モーター」「片側1個か2個か」 |
| 電源 | **2S LiPo**(7.4V) | モーターの定格が7.4V |
| スパーギア | **MK3と同じものを使う** | ギア比はピニオンの歯数で合わせる(下記「ギア比」) |
| 吸引 | ファンを続ける。**吸引力600gを目標**(MK3は約400g) | 下記「グリップ」 |

## 検討中

| 項目 | 案 | メモ |
|---|---|---|
| ギア比 | 4〜5(ピニオンの歯数で決まる) | スパーの歯数と、モーターの軸に付けられる最小のピニオンを確認する |
| モータードライバ | 2Sで使えて、電流を測れるもの | 電流をソフトで制限するため必須(下記「モーター」) |
| 電流の制限 | まず片側3A。温度を実測して見直す | 連続で流してよい電流が公表されていない |
| 電池・ファン | 2Sの容量・放電できる電流、ファンを2Sで直接回すか | ピークはモーター2個+ファンで10A前後になりうる |
| MCU | H7系(STM32H723など、RAM約564KB)か、F4のRAMが大きい品種 | MK3はRAM 112KB/128KBで、32×32もログ延長もできない。ダイクストラ約9ms(-O0) |
| 不揮発メモリ | SPIのFRAMかFlashを追加 | 迷路・会場の倍率・ターンのパラメータ・ログを保存し、会場でビルドし直さずに済むようにする |
| 通信 | USB-C+無線(BLE) | パラメータの書き換えとログの取り出し |
| 壁センサ | 4本(MK3と同じ)か、斜め用を足して6本 | 斜め走行中の補正、前壁の近距離(60mm未満) |
| IMU・エンコーダ | MK3と同じ(LSM6DSR、SPIの磁気式) | 回転が速くなるので、エンコーダの分解能と読み取り時間を確認する |
| 制御周期 | 2〜4kHz(MK3は1kHz) | MCUを決めてから |
| 質量・タイヤ径 | 90g・23mmと仮定して計算した | 決まったら計算し直す |

## MK3の現状

| 項目 | MK3 |
|---|---|
| MCU | STM32F446RE(180MHz、Flash 512KB / RAM 128KB) |
| 機体 | 全長120mm・幅70mm・78g、トレッド55mm、タイヤ径23.1mm、ギア比1.7073(70/41) |
| モーター | 巻線抵抗5.4Ω、トルク定数2.63mNm/A、16V基準 |
| ドライバ | MP6550 |
| センサ | 壁センサ4本(FL/L/R/FR)、LSM6DSR、SPIの磁気式エンコーダ |
| 吸引 | 約400g |
| 走り | 最短はコーナー2000〜2400、直線6000mm/s、加速度20000〜25000 |

MK3の課題:

1. 直線の加速が約25000mm/s²で、左右のモーターの電圧(duty)が張り付く
2. V90の限界(約2200)も、滑りではなくdutyの張り付き
3. RAMが足りない(16×16で112KB/128KB)。32×32はビルドできない
4. 会場の感度合わせのたびに、値を書き写してビルドし直す。迷路はRAMにしか残らない
5. ギアの滑りが疑われている(2026-10-08)

## モーター: NFP-D8620-3665-3-7.4

販売ページ: <https://nfpshop.com/product/8-6-x-20mm-coreless-dc-motor-high-efficiency-low-noise>

| 項目 | 値 |
|---|---|
| 定格電圧 | 7.4V |
| 巻線抵抗 | 1Ω |
| トルク定数 | 15 g·cm/A(1.47 mNm/A) |
| 無負荷回転数 / 無負荷電流 | 46,000rpm / 140mA |
| 停止トルク / 停止電流 | 108.8 g·cm(10.7 mNm)/ 7.41A |
| 最大出力 / 最大効率 | 12.8W / 72% |
| 重さ / 大きさ | 5.3g / 直径8.6mm × 長さ20mm |

- 無負荷回転数から求めた逆起電力定数は1.51 mV/(rad/s)で、トルク定数1.47とほぼ一致する(表の値は矛盾していない)
- モーター定数 Kt/√R は1.47(MK3は1.13)。同じ発熱で1.3倍のトルクが出る
- **受注生産で約4週間かかる**。予備も含めて早めに注文する
- **連続で流してよい電流が公表されていない**。電圧をかけっぱなしにすると最大7.4A(発熱 I²R 最大約55W)になるので、ドライバで電流を測ってソフトで制限する
- 軸の直径は外形図で確認してからピニオンを選ぶ

## 計算

計算は`docs/calc/drive_calc.py`で出せる(`python3 docs/calc/drive_calc.py --gear 4 5` のようにギア比を指定できる)。仮定: 質量90g、タイヤ径23mm、トレッド55mm、電源7.4V、摩擦・ドライバの損失・電池の電圧降下は入れていない。MK3の値で計算した直線の加速の上限(約30m/s²)が、実機で電圧が張り付いた25000〜28000mm/s²とほぼ合うことを確認している。

### 直線の加速(片側1個)

| ギア比 | 電圧の上限(0 / 3 / 6 m/s) | 片側3Aに制限 | 6m/sでの回転数 | 無負荷の最高速 |
|---|---|---|---|---|
| MK3(1.71) | 30 m/s²(0 m/s) | | | |
| 3 | 63 / 53 / 43 m/s² | 26 m/s² | 14,900rpm | 18.8 m/s |
| 4 | 84 / 66 / 48 | 34 | 19,900rpm | 14.1 m/s |
| **5** | 105 / 77 / 49 | **43** | 24,900rpm | 11.3 m/s |
| 6 | 126 / 86 / 46 | 51 | 29,900rpm | 9.4 m/s |

- 抵抗が小さいので、加速の上限は電圧ではなく**電流(発熱)**で決まる
- 6m/sでも回転数は無負荷の約半分なので、高速での伸びも残る

### グリップ

MK3はV90 2200(横91.5m/s²、78g、吸引400g)で滑らず、先にdutyが張り付いた。ここから摩擦係数は**μ ≥ 1.52**(下限)。2輪なので吸引の力はほぼすべて駆動輪にかかるとした。

| 構成 | 吸引400g | 吸引600g |
|---|---|---|
| 片側1個(90g) | 81 m/s² 以上 | **114 m/s² 以上** |
| 片側2個(102g) | 73 m/s² 以上 | 103 m/s² 以上 |

- 直線の加速は、グリップよりずっと手前でモーター(電流・発熱)が限界になる
- コーナーのグリップの限界は、吸引600g・片側1個でV90 約2460以上(MK3の横Gの限界の1.25倍、速度で1.12倍)。吸引400gのままだと機体が重くなる分、MK3より下がる(0.94倍)。**吸引600gが前提**
- 吸引の中心が車軸から前後にずれると、機体の端が床に当たってグリップが減る。ファンは車軸の近くに置く

### ターン中のduty(V90)

ターンの入りでは、機体を回し始めるために外側の車輪に大きなトルクが要り、外側の車輪は機体より速く回るので逆起電力も大きい。MK3の`Motor_Sula_COS`の角速度の形と、`G_Turn2000`のV90(2000deg/s・130000deg/s²を速度に合わせて換算)で、外側の車輪に必要な電圧を計算した。慣性モーメントは「MK3がV90 2200でちょうど100%」になるように逆算した(219 g·cm²。電池の電圧降下などもここに含まれる)。MK4は1.15倍とした。

| V90の速度 | MK3 | ギア比3 | ギア比4 | ギア比5 | ギア比6 |
|---|---|---|---|---|---|
| 2200 | **100%** | 59% | 53% | 51% | 52% |
| 2400 | 118% | 68% | 61% | 58% | 59% |
| 2700 | 149% | 84% | 74% | 70% | 70% |
| 3000 | 183% | 102% | 88% | 83% | 81% |
| 3300 | 221% | 121% | 104% | 96% | 94% |

- ギア比4〜5なら、V90は約3000まで張り付かない。**MK4のコーナーの限界はdutyではなくグリップになる**
- %の値そのものはおおよそ。MK3との比(約半分)のほうが信頼できる

### 片側1個か2個か

片側2個(同じスパーに2つのピニオン、1つのドライバに並列)も検討した。

| | 片側1個 | 片側2個 |
|---|---|---|
| 質量 | 90g | 102g(+12g) |
| 直線の加速35m/s²での電流 / 発熱合計 | 2.5A/個、12W | 1.4A/個、8W |
| 6m/sでの電圧の上限 | 49 m/s² | 87 m/s² |
| コーナー(グリップ、吸引600g) | **V90 約2460以上** | 約2330以上 |
| 機構 | シンプル | ピニオン2つのかみ合わせ、ギアの滑りの心配が増える |
| 電源 | | ピーク電流が大きい |

**片側1個にした。** コーナーの限界がグリップになったので軽い方が有利で、片側2個の利点は直線の加速と熱の余裕だけ。基板とフレームには、スパーの反対側に2個目のモーターを置ける場所と配線を残しておき、温度を実測して熱が厳しければ2個にする。

## ギア比

スパーギアはMK3と同じものを使い、ギア比はピニオンの歯数で決める(ギア比 = スパーの歯数 / ピニオンの歯数)。

- 目標は4〜5。ギア比3だと片側3Aでの加速がMK3並み(26m/s²)にとどまる
- ターン中のdutyはギア比4〜6でほとんど変わらないので、直線の加速で決めてよい
- モーターの位置(中心距離)はピニオンに合わせて変わる。モーターの取り付けはMK4で作り直すので問題ない
- 決まったら`Define.h`の`GEARRATIO`を歯数の比で書く
