## 3. JLC3DP(印刷する部品)

材料はすべて **光造形(SLA)、JLC Temp Resin**(荷重たわみ温度 101°C、精度 ±0.2mm / 100mm、すすめる壁 0.8mm 以上)。1回の注文にまとめる。

| 部品 | ファイル | 数 | 1個の重さ |
|---|---|---|---|
| モーターマウント v9(右) | `mechanical/motor_mount/motor_mount_R_v9.stl` | 3 | 1.29g |
| モーターマウント v9(左) | `mechanical/motor_mount/motor_mount_L_v9.stl` | 3 | 1.29g |
| ファンの台 v1 | `mechanical/fan_mount/fan_mount_v1.stl` | 3 | 1.64g |
| ホイール v1(右) | `mechanical/wheel/wheel_R_v1.stl` | 3 | 0.38g |
| ホイール v1(左) | `mechanical/wheel/wheel_L_v1.stl` | 3 | 0.38g |

- 仕上げは標準(色付け・研磨なし)
- 備考に書くこと: 「φ1.6 の穴はあとでタップを立てるので、ふさがないでください」「穴のまわりの細い当たり面は削らないでください」
- JLC3DP は M6 未満のねじ山を作らないので、M2 は届いてから自分でタップを立てる(`docs/mount.md`の「7. 注文」)

## 届いたら

- モーターマウント: `docs/mount.md`の「7. 注文」の「届いたら」(割れ・欠けを見る、タップ、軸受とモーターの圧入、かみ合いの確認)
- ファンの台・羽根: 羽根と輪のすき間(半径0.5mm)を回して確かめる。羽根の振れを見る
- ホイール: タイヤの内径と幅を測る
- 組んだら、吸引力・ファンの電流・ファンのモーターの温度・滑り出す力(μ)を測る
