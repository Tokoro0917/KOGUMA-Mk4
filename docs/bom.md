# MK4 部品表(案)

2026-10-12作成。回路図を描き始めるための一覧。ピンの割り当ては`docs/pinmap.md`、決めた理由は`docs/spec.md`。

「根拠」の列: **DS** = データシートの値、**MK3** = MK3(KOGUMA-CHAN.MkIIの回路図)と同じ、**仮** = 仮の値で、回路図を描くときに決める、**要選定** = 品番をこれから決める。
