電源スイッチの回路(MK3と同じ): 電池の+ → MOSFETのソース、ドレイン → VBAT。ゲートとソースの間に100kΩ(R1、ふだんはOFF)。スライドスイッチでゲートをGNDに落とすとONになり、VGS = −電池の電圧(3Sで最大−12.6V)。

- この回路は**電池の逆接続は防げない**(逆につなぐと、MOSFETの中のダイオードを通って回路に逆の電圧がかかる)。電池のコネクタは逆に挿さらない形のものにする
- ONにした瞬間、VBATのコンデンサへの突入電流が流れ、配線のインダクタンスとの振動でVBATが最悪で約2倍まで跳ねることがある。**ゲートとドレインの間の C10(22nF)で VBAT の立ち上がりを遅くする**(2026-11-06 のレビュー(`docs/review_2026-11-06.md`)。ゲートとソースの間の C1 だけでは ON が遅れるだけで、VBAT は約11µs で立ち上がり、突入電流が約40〜60A になっていた)。C1 を 220nF にして C1:C10 = 10:1 にし、スイッチ OFF で電池を挿したときにゲートに乗る電圧を約 −1.1V(Vth の最小 1.7V より低い)に抑える。ON まで約0.75ms、立ち上がり約0.3ms、突入約3A、OFF は約30ms。0.3ms・約18W の SOA はデータシートで確かめる
