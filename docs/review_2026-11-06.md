## 全体の評価

- **つなぎ方の誤り・焼けるような誤りはない**。ERC エラー 0。46本のピンは ST のピン定義と一致し、MP6551・NJU6080・MT6835・LSM6DSR・OPA2354 のピンの並びも合っている
- 直したほうがよいのは、**電源を入れた瞬間とリセット中のふるまい**(ソフトスタート、PB4 のプルアップ、浮いた CS)と、**ノイズの通り道**(ファンの電流の輪、NT1 の位置、VDDA・+3V3A のフィルタの共振)
- 受光アンプそのもののノイズは小さく、問題にならない(484µV rms、16ビットで約10 LSB、12ビットで約0.6 LSB)

## ソフトでやること

- 壁センサは、点灯・消灯を車輪とファンの PWM の同じ位置で読む。点灯から約7µs 待つ(NJU6080 の遅れ 2.5µs を含む)
- モーターの CM は PWM に同期して読む(2.35k/1nF は 50kHz で −1.9dB しか減らない)。ON と OFF の真ん中を2回読んで平均する(約 +1%)
- ファンの電流(1k/1µF)は同期は要らない(50kHz で −50dB)
- 左右のドライバの PWM の極性を逆にして、VBAT のリップル電流を約半分に
- SPI2 は 16.6MHz 以下(例: 12.5MHz)、CS を下げてから SCK まで 100ns 以上。MT6835 は電源を入れてから 64ms 待つ
- 起動直後に電源の設定を Direct SMPS に。UART_RX(PB7)は内部プルアップ

## 配線の注意(まとめ)

- VBAT・PGND の幹は 6A で約 2.5mm 以上、モーターの出力は 3A で約 1mm 以上(今のネットクラス 0.5mm・0.4mm はパッドの出口だけ)。層を移る所はビアを複数
- C2〜C4・ドライバ・DC-DC の GND を1か所に集め、その近くに NT1。MCU とドライバの間の信号は NT1 のそばで分かれ目を越える
- PGND を前に延ばさない。受光アンプ・WALL_*・CM の線の下は裏の GND のベタを切らない
- MP6551 の 100nF は VIN(2番)に最短、GND 側はすぐビア
- マイコン: EP に GND のビアを複数。SMPS のループ(VDDSMPS → L1 → C54 → VSSSMPS)を最小にし、アンプと ADC から離す。Y1 は PH0・PH1 のすぐそば
- 受光アンプ: フォトダイオードから − 入力までを最短に。Rf・Cf はピンの真上、下のベタは抜くかガード。スイッチングする線から離して GND で囲む(1fF の結合でも約24mV)
- ブザーは MT6835 から 15mm 以上離す。IMU からも離す

## 確かめて問題なかったこと(抜粋)

- MP6551 の周り(CM 4.7k × 2、VIN 100n + 10µ、SR 0Ω)はデータシートの例と一致。入力は中で 500kΩ のプルダウンなので、リセット中もモーターは止まっている
- 3.3V の DC-DC: RFB 1.30k で 3.31V、出力のコンデンサ合計約86µF(上限 150µF 以内)
- MCU: SMPS の外付け部品は DS13311 表16と一致。HSE の gm_crit は十分小さい
- 受光アンプ: 帯域 457kHz、位相余裕 82°、Cf 0.5pF はこのままでよい(±0.3pF でも安定)
- MT6835 のバス共用(CSN が H のとき MISO はハイインピーダンス)、J5・J6 のパッドの並びと J6 の 180° 回転
- LSM6DSR の SPI と INT1(PD2)
